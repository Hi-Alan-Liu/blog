Docker Desktop on Windows (ruby on rails)

因工作環境需求，必須在 Windows Server 2019 部署 Ruby on Rails，但 Capistrano 不支援部署至 Windows，因此改用 Docker Desktop 解決。

準備

  1. 註冊 Docker Hub
  2. 下載並安裝 Docker Desktop
  3. 將 Docker Desktop 的 Containers 切換為 Linux（選單出現 Switch to Windows containers 代表目前已是 Linux）

一、建立 Dockerfile

參考 Docker docs - Compose and Rails 建立 Dockerfile。我在 Docker Desktop v4.10.1 照官方步驟無法正常啟動，因此參考 Docker 上的 Windows 調整如下（Ruby 2.4.4，並加上 imagemagick 與 SQL Server 需要的 FreeTDS）：

指令 說明
FROM 基底 Image，這裡使用 Ruby 2.4.4
RUN 執行 Linux 指令，安裝與設定 Image 需要的套件
WORKDIR 指定工作目錄
COPY / ADD 複製檔案；ADD 為進階版，可自動解壓縮
ENV 設定環境變數
EXPOSE 宣告容器使用的 port
CMD docker run 時執行的指令
