給美編的 Claude Code 教學：從參考圖到 Illustrator .ai 與 PNG

美編同事問我：「聽說 Claude 可以幫忙做圖，那我要怎麼用？」我第一反應是 —— 它不是生圖 AI，但它會寫 Illustrator 看得懂的東西。這篇用一個實際案例，帶你從終端機輸入第一句話開始，丟給 Claude 參考圖與設計想法，最後拿到一個分好圖層的 .ai 檔，以及一整包 1x / 2x / 3x 的透明 PNG。

本篇跳過安裝，假設你已經能在終端機輸入 claude 啟動 Claude Code。指令細節可參考 Claude Code 常用指令教學。

文中穿插工程師「阿哲」與美編「小芸」的對話，是這篇教學實際討論時的片段。

先講清楚：Claude 能做什麼、不能做什麼

💬 小芸：所以我丟一張圖，它就會畫一張新的給我？
💬 阿哲：不是喔。Claude 「看得懂」圖片，但它不是 Midjourney 那種直接吐出點陣圖的生圖模型。它做的是把你的想法翻譯成向量指令，讓 Illustrator 去畫。

適合交給 Claude 不適合交給 Claude
幾何風格的圖示、Logo 草案、資訊圖表 手繪質感插畫、寫實人物
一次建好多個畫板、圖層、色票 需要「感覺對了」的細膩筆觸
批次輸出多尺寸 PNG、重新命名 取代你的美感判斷

一句話：Claude 是一個很會寫腳本、聽得懂設計語言的助理，最後的美感把關還是你。

Step 1：準備工作資料夾

開終端機：在檔案總管對專案資料夾按右鍵 →「在終端機中開啟」，輸入 claude 按 Enter，看到對話框就能開始用中文打字。離開時輸入 /exit。

Claude 只看得到你所在資料夾裡的東西，先準備好這樣的結構（資料夾名稱請用英文、不含空白，中文路徑容易讓 Illustrator 腳本找不到檔案）：

上半段由美編填，下半段的「技術規則」照抄即可 —— Illustrator 的腳本引擎很舊，先講清楚可以避免 Claude 寫出無法執行的語法。

不想自己寫，也可以直接說：「幫我建立 CLAUDE.md，主色是 #6B4226……」讓 Claude 產生後你再修。

Step 2：丟參考圖，先讓它「說出」看到什麼

把圖片檔直接拖進終端機視窗（會自動帶入路徑），或在對話中寫 ref/sketch.jpg 即可。

最推薦的習慣是：不要一丟圖就叫它畫，先確認它理解得跟你一樣。

Claude 回覆後，像跟同事對稿一樣修正它：「第三個不是茶壺，是手沖壺，壺嘴要細長」。這一步花 2 分鐘，可以省掉後面 20 分鐘來回。

💬 小芸：程式碼我看不懂耶。
💬 阿哲：不用看懂。要改什麼就用中文說，例如「把畫板改成 1080×1080」，它會自己改腳本。

執行腳本

兩種方式擇一：

  • 請 Claude 幫你執行：先打開 Illustrator，再對 Claude 說「幫我用 Illustrator 執行 output/make-icons.jsx」。Illustrator 會自己畫完、存檔、輸出，你只要去 output/ 收成果。
  • 在 Illustrator 手動執行：檔案 → 指令碼 → 其他指令碼（Ctrl + F12），選擇那支 .jsx 檔。

💡 這支腳本請留著：之後改完設計，重跑一次就能重新輸出全部 PNG，不用再一個一個轉存。下個專案也能沿用。

只做一個圖示的話，也可以請它「畫成 SVG」，再用 Illustrator 開啟、另存成 .ai。

Step 4：看結果、用「設計語言」來回修

第一版通常有七成像。這時候用你平常對稿的講法就行，Claude 聽得懂設計術語：

幾個好用的回饋技巧：

  • 指名檔案：說「看 icon-bean@2x.png」，讓它重新讀圖比對，而不是憑記憶修。
  • 給數字：「往上一點」不如「往上 16px」。
  • 一次講 2～4 點：太多容易漏，太少則來回次數變多。
  • 整組比較：「把四張 PNG 並排看，哪一個的線條密度跟其他不一致？」它會自己挑出問題。

最後一哩 —— 某條曲線的弧度、某個角度的手感 —— 直接在 Illustrator 裡用滑鼠調，通常比用文字描述快。Claude 負責 80% 的骨架與重複工作，最後 20% 交給你的手。

結語

💬 小芸：做完才發現，我其實一直在做我擅長的事 —— 看稿、挑毛病、下判斷。
💬 阿哲：對，畫板、圖層、輸出這些「手很忙但腦不用動」的事，就丟給它。

Claude Code 對美編最大的價值，不是取代你畫圖，而是把規範化、重複性、批次性的工作接過去。第一次可能要花點時間習慣終端機，但只要那支輸出腳本存下來，往後每個專案都能省下一大段時間。
