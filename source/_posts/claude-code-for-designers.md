美編同事問我：「聽說 Claude 可以幫忙做圖，那我要怎麼用？」我第一反應是 —— 它不是生圖 AI，但它會**寫 Illustrator 看得懂的東西**。這篇用一個實際案例，帶你從終端機輸入第一句話開始，丟給 Claude 參考圖與設計想法，最後拿到一個**分好圖層的 .ai 檔**，以及一整包 **1x / 2x / 3x 的透明 PNG**。

<!-- more -->

> 本篇跳過安裝，假設你已經能在終端機輸入 `claude` 啟動 Claude Code。指令細節可參考 {% post_link claude-code-commands 'Claude Code 常用指令教學' %}。
>
> 文中穿插工程師「阿哲」與美編「小芸」的對話，是這篇教學實際討論時的片段。

## 先講清楚：Claude 能做什麼、不能做什麼

> 💬 **小芸**：所以我丟一張圖，它就會畫一張新的給我？
> 💬 **阿哲**：不是喔。Claude 「看得懂」圖片，但它不是 Midjourney 那種直接吐出點陣圖的生圖模型。它做的是**把你的想法翻譯成向量指令**，讓 Illustrator 去畫。

| 適合交給 Claude | 不適合交給 Claude |
| --- | --- |
| 幾何風格的圖示、Logo 草案、資訊圖表 | 手繪質感插畫、寫實人物 |
| 一次建好多個畫板、圖層、色票 | 需要「感覺對了」的細膩筆觸 |
| 批次輸出多尺寸 PNG、重新命名 | 取代你的美感判斷 |

一句話：**Claude 是一個很會寫腳本、聽得懂設計語言的助理**，最後的美感把關還是你。

---

## Step 1：準備工作資料夾

**開終端機**：在檔案總管對專案資料夾按右鍵 →「在終端機中開啟」，輸入 `claude` 按 Enter，看到對話框就能開始用中文打字。離開時輸入 `/exit`。

Claude 只看得到你所在資料夾裡的東西，先準備好這樣的結構（**資料夾名稱請用英文、不含空白**，中文路徑容易讓 Illustrator 腳本找不到檔案）：

```text
coffee-icons/
├── ref/          ← 參考圖、手稿照片、mood board
├── output/       ← .ai 與 PNG 輸出位置
└── CLAUDE.md     ← 品牌規範
```

### 用 CLAUDE.md 寫下品牌規範

`CLAUDE.md` 是 Claude Code 每次啟動都會自動讀的檔案，等於一份**常駐的設計 brief**，不用每次重新交代主色和線條粗細：

```markdown
# 白鷺咖啡 圖示專案

## 品牌規範
- 主色 #6B4226（咖啡棕）、輔色 #F2E6D8（奶泡白）、強調色 #D98E04（焦糖）
- 風格：線性圖示，圓角端點、圓角轉折
- 畫板 512×512 px，筆畫 24 px，四周保留 48 px 安全區，背景透明

## 技術規則
- Illustrator 腳本使用 ExtendScript（ES3 語法）：不要用 let、const、箭頭函式
- 一個圖示 = 一個畫板 + 一個圖層，名稱格式 icon-英文小寫（例：icon-latte）
- 輸出：output/coffee-icons.ai，PNG 放 output/png/，含 1x、@2x、@3x
```

上半段由美編填，下半段的「技術規則」照抄即可 —— Illustrator 的腳本引擎很舊，先講清楚可以避免 Claude 寫出無法執行的語法。

不想自己寫，也可以直接說：「幫我建立 CLAUDE.md，主色是 #6B4226……」讓 Claude 產生後你再修。

## Step 2：丟參考圖，先讓它「說出」看到什麼

把圖片檔**直接拖進終端機視窗**（會自動帶入路徑），或在對話中寫 `ref/sketch.jpg` 即可。

最推薦的習慣是：**不要一丟圖就叫它畫**，先確認它理解得跟你一樣。

```text
ref/sketch.jpg 是我手畫的四個圖示草稿，ref/mood.png 是風格參考。
先不要寫任何檔案，請用條列描述：
1. 你看到的四個圖示分別是什麼
2. 參考圖的風格特徵（線條、圓角、留白、配色）
3. 你打算怎麼在 512×512 畫板上構圖
```

Claude 回覆後，像跟同事對稿一樣修正它：「第三個不是茶壺，是手沖壺，壺嘴要細長」。**這一步花 2 分鐘，可以省掉後面 20 分鐘來回。**

---

## Step 3：請它寫腳本，產出 .ai 與 PNG

確認理解無誤後，一句話交代要什麼：

```text
寫一支 Illustrator 腳本 output/make-icons.jsx：
- 建立 4 個 512×512 畫板，分別是 latte、pour-over、bean、cake
- 每個圖示一個圖層，把品牌三色加進色票
- 存成 output/coffee-icons.ai
- 再把每個畫板輸出成 1x、@2x、@3x 透明 PNG 到 output/png/
```

Claude 寫出的腳本會分成四段，你不需要看懂程式碼，知道每段在做什麼就好：

```javascript
// 1. 建立文件：4 個 512×512 畫板
// 2. 加入品牌色票、每個圖示建立圖層並繪製
// 3. 存成 coffee-icons.ai
// 4. 每個畫板輸出 1x / @2x / @3x 透明 PNG
```

> 💬 **小芸**：程式碼我看不懂耶。
> 💬 **阿哲**：不用看懂。要改什麼就用中文說，例如「把畫板改成 1080×1080」，它會自己改腳本。

### 執行腳本

兩種方式擇一：

- **請 Claude 幫你執行**：先打開 Illustrator，再對 Claude 說「幫我用 Illustrator 執行 `output/make-icons.jsx`」。Illustrator 會自己畫完、存檔、輸出，你只要去 `output/` 收成果。
- **在 Illustrator 手動執行**：**檔案 → 指令碼 → 其他指令碼**（`Ctrl + F12`），選擇那支 `.jsx` 檔。

> 💡 **這支腳本請留著**：之後改完設計，重跑一次就能重新輸出全部 PNG，不用再一個一個轉存。下個專案也能沿用。
>
> 只做一個圖示的話，也可以請它「畫成 SVG」，再用 Illustrator 開啟、另存成 .ai。

## Step 4：看結果、用「設計語言」來回修

第一版通常有七成像。這時候**用你平常對稿的講法就行**，Claude 聽得懂設計術語：

```text
看 output/png/icon-latte@2x.png：
- 杯子視覺重心偏下，往上移 16px 做光學置中
- 拉花太複雜，簡化成一個愛心
- 杯耳的筆畫看起來比杯身粗，統一成 24px
改完重新執行腳本。
```

幾個好用的回饋技巧：

- **指名檔案**：說「看 `icon-bean@2x.png`」，讓它重新讀圖比對，而不是憑記憶修。
- **給數字**：「往上一點」不如「往上 16px」。
- **一次講 2～4 點**：太多容易漏，太少則來回次數變多。
- **整組比較**：「把四張 PNG 並排看，哪一個的線條密度跟其他不一致？」它會自己挑出問題。

最後一哩 —— 某條曲線的弧度、某個角度的手感 —— **直接在 Illustrator 裡用滑鼠調**，通常比用文字描述快。Claude 負責 80% 的骨架與重複工作，最後 20% 交給你的手。

## 常見問題

| 狀況 | 解法 |
| --- | --- |
| 腳本執行出現錯誤訊息 | 把錯誤訊息整段貼給 Claude，說「執行出現這個錯誤，幫我修」 |
| 找不到檔案、存檔失敗 | 資料夾與檔名改用英文、不含空白 |
| PNG 背景是白的 | 告訴 Claude「PNG 要透明背景，不要有白色底圖」 |
| 交件後字型被替換 | 請 Claude 在腳本中加上「文字建立外框」 |

## 速查卡

| 我想要… | 對 Claude 說… |
| --- | --- |
| 確認它看懂參考圖 | 「先不要寫檔案，描述你在 `ref/xxx.jpg` 看到什麼」 |
| 一次建好一整組 .ai | 「寫 Illustrator 腳本，建 N 個畫板、圖層、色票，存成 .ai」 |
| 直接執行 | 「幫我用 Illustrator 執行 `xxx.jsx`」 |
| 微調 | 「看 `xxx@2x.png`，○○ 往上 16px、線條統一 24px，改完重跑」 |
| 批次出圖 | 「把每個畫板輸出 1x / @2x / @3x 透明 PNG」 |

## 結語

> 💬 **小芸**：做完才發現，我其實一直在做我擅長的事 —— 看稿、挑毛病、下判斷。
> 💬 **阿哲**：對，畫板、圖層、輸出這些「手很忙但腦不用動」的事，就丟給它。

Claude Code 對美編最大的價值，不是取代你畫圖，而是把**規範化、重複性、批次性**的工作接過去。第一次可能要花點時間習慣終端機，但只要那支輸出腳本存下來，往後每個專案都能省下一大段時間。
